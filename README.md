🏠 Roommate Dashboard

Roommate Dashboard is a full-stack web application built with Spring Boot that helps roommates manage shared household responsibilities including expenses, chores, grocery lists, and payments.

The system is designed to reduce confusion around shared living by providing a centralized dashboard for tracking financial and household activity.

🚀 Tech Stack
Java
Spring Boot
Spring MVC
Spring Data JPA
Thymeleaf
H2 (Development)
PostgreSQL (Production-ready)
✨ Features
💸 Expense tracking with equal and custom bill splitting
📊 Real-time balance calculation between roommates
🧹 Chore assignment with automatic rotation
🛒 Shared grocery list with purchase tracking
💰 Direct roommate-to-roommate payment logging
🧾 Activity log for tracking all actions
🏠 Household creation and invite system
